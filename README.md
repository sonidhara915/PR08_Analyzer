# 🔢 NumPy Analyzer

A simple and interactive **NumPy Array Analysis Program** built using **Python and NumPy**.

This project provides a menu-driven interface to create, manipulate, combine, search, filter, sort, and perform mathematical and statistical operations on NumPy arrays.

---

## ✨ Features

- 🔢 Create NumPy arrays
- ➕ Perform addition
- ➖ Perform subtraction
- ✖️ Perform multiplication
- ➗ Perform division
- ✂️ Perform array slicing
- 🔗 Combine arrays vertically and horizontally
- 🔍 Search for specific values
- 🔃 Sort array values
- 🎯 Filter values based on conditions
- ∑ Calculate sum and mean
- 📊 Calculate median
- 📉 Calculate standard deviation
- 📐 Calculate variance
- 🖥️ Interactive menu-driven interface

---

## 📌 Main Operations

### 1. 🔢 Create NumPy Array

The program allows users to create arrays by entering elements and specifying the number of rows and columns.

It covers:

- 1D Array
- 2D Array
- 3D Array concepts

The created array is stored and can be used for further operations.

---

### 2. 🧮 Mathematical Operations

The program supports basic element-wise mathematical operations.

| Operation | Description |
|---|---|
| ➕ Addition | Adds corresponding elements |
| ➖ Subtraction | Subtracts corresponding elements |
| ✖️ Multiplication | Multiplies corresponding elements |
| ➗ Division | Divides corresponding elements |

---

### 3. ✂️ Array Slicing

Array slicing allows users to select a specific portion of a 2D array.

It can be used to select:

- Specific rows
- Specific columns
- A particular range of elements

---

### 4. 🔗 Combine Arrays

The program provides two methods for combining arrays.

#### Vertical Stack

Combines arrays row-wise using the concept of **vstack**.

#### Horizontal Stack

Combines arrays column-wise using the concept of **hstack**.

---

### 5. 🔍 Search, Sort & Filter

The analyzer provides different array operations:

- 🔍 **Search** – Finds the position of a particular value
- 🔃 **Sort** – Sorts array values row-wise
- 🎯 **Filter** – Displays values greater than a given limit

---

## 📊 Statistical Operations

The program can calculate basic statistical values from an array.

| Statistic | Purpose |
|---|---|
| ∑ Sum | Calculates the total of all values |
| 📊 Mean | Calculates the average value |
| 📍 Median | Finds the middle value |
| 📉 Standard Deviation | Measures the spread of data |
| 📐 Variance | Measures the variation in data |

## 🎯 Project Objective

The main objective of this project is to understand and practice **NumPy array operations** through an interactive application.

The project covers the following workflow:

> **Array Creation → Mathematical Operations → Slicing → Combining → Searching → Sorting → Filtering → Statistics**
